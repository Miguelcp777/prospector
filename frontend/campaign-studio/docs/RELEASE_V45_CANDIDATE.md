# Aurevanta Campaign Studio v45 · entrega final UX V2

La v45 reorganiza la experiencia completa sobre la base funcional de la v44. No sustituye el motor ni modifica sus contratos: cambia la jerarquía, la navegación, la exposición de controles y el sistema de plantillas.

Principales incorporaciones:

- Inicio orientado a crear, continuar o importar.
- Cinco espacios principales sin accesos repetidos.
- Cabecera compacta y menú Más acciones.
- Paneles laterales plegables y maqueta con mayor prioridad.
- Modo guiado persistente de cinco fases y modo profesional completo.
- Biblioteca con recomendadas, Premium, todas y clásicas.
- 15 plantillas maestras Premium con cinco variantes cada una.
- Aplicación independiente de estilo, estructura o ambos.
- Creación de variantes y plantillas maestras desde una campaña.
- Solapamientos marcables como intencionados.
- Barra inferior y paneles deslizables para edición móvil.
- Registro central de espacios y acciones para futuras ampliaciones.
